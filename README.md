## 🗂️ Directory Overview

### 1. `Newsletter_Releases/`
Contains the final, polished versions of the newsletter, organized chronologically by release month and format.

| Subdirectory       | Format | Purpose                              |
|--------------------|--------|--------------------------------------|
| `May_2026/pdf/`    | PDF    | High-quality print & distribution    |
| `May_2026/png/`    | PNG    | Web usage and general sharing        |
| `May_2026/jpeg/`   | JPEG   | Lightweight format for quick sharing |

---

### 2. `Brand_Logos/`
Contains official branding materials and icons used across all publications and platforms.

| Asset                    | Description                        |
|--------------------------|------------------------------------|
| CQTCS Official Logo      | Primary department identity mark   |
| Christ University Logo   | University-level branding          |
| GitHub Icon              | Social media icon for GitHub       |
| Instagram Icon           | Social media icon for Instagram    |
| LinkedIn Icon            | Social media icon for LinkedIn     |

---

### 3. `Team_Profiles/`
Organized photos of the newsletter team and contributors.

```
Team_Profiles/
├── Original/     ← Raw, uncropped profile photos (full aspect ratio)
└── Circular/     ← Processed, circular-cropped, ready for layout insertion
```

---

### 4. `Design_Assets/`
Graphical elements and backgrounds used to construct the newsletter pages.

```
Design_Assets/
├── Backgrounds/
│   ├── Quantum-themed backgrounds
│   ├── Profile backdrops
│   └── Illustrative drawings
│       ├── Human-robot diagrams
│       └── Campus drawings
│
└── Elements/
    ├── Coordinator's Note section element
    ├── Publications section element
    └── Research Spotlight section element
```

---

### 5. `Event_Photos/`
Photos and illustrations related to specific CQTCS events.

| Asset                           | Description                              |
|---------------------------------|------------------------------------------|
| Inauguration Group Photos       | Team photos from the launch event        |
| Inauguration Block Designs      | Graphic blocks used in event coverage    |
| Campus Drawing                  | Illustrated Christ University campus art |
| Human-Robot Interaction Diagram | Visual for robotics/AI-themed content    |

## 📝 Naming Conventions

Files follow standardized naming to ensure consistency and cross-platform compatibility:

| Convention        | Example                        | Used For                          |
|-------------------|--------------------------------|-----------------------------------|
| `hyphenated-case` | `human-robot-diagram.png`      | Image and media files             |
| `PascalCase`      | `ChristUniversityLogo.svg`     | Brand assets and logos            |
| `YYYY_MM/`        | `May_2026/`                    | Date-stamped release directories  |
