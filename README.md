CQTCS Design Archive

Official design and visual communication repository for  
CQTCS — Center for Quantum Technologies and Complex Systems**  
CHRIST (Deemed to be University), Bangalore.

About

This repository serves as the centralized archive for all creative, branding, and visual communication materials developed for CQTCS activities, academic outreach, events, workshops, seminars, conferences, and institutional promotions.

The repository is maintained to ensure:

- Organized storage of design assets
- Proper version control for creative works
- Consistent institutional branding
- Easy access to editable and exported files
- Long-term archival of departmental media content

Repository Structure

posters/            → Final poster designs and promotional creatives
design-materials/   → Course brochures, informational documents, and design assets
design-drafts/      → Trial versions, experimental layouts, and work-in-progress designs
exports/            → Exported PNG, PDF, and delivery-ready files
templates/          → Reusable templates and layout resources
logos/              → Official CQTCS and university branding assets
