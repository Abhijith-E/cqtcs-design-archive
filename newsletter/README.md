# CQTCS Newsletter Assets

Welcome to the assets repository for the **Department Center for Quantum Technologies and Complex Systems (CQTCS)** newsletter, Christ University, Bangalore.

This repository contains all the design elements, team profiles, brand logos, and final releases for **Quanicle** (Vol 01, Issue 01, July 2026).

## 📁 Repository Structure

The assets have been systematically organized into the following directories for ease of access and professional workflow:

### 1. `Newsletter_Releases/`
Contains the final, polished versions of the newsletter, organized chronologically by release month and format.
- **`May_2026/`**: The May 2026 release files.
  - **`pdf/`**: High-quality PDF for print and distribution.
  - **`png/`**: PNG images for web and general use.
  - **`jpeg/`**: JPEG images for quick sharing.

### 2. `Brand_Logos/`
Contains official branding materials and icons.
- CQTCS Official Logo
- Christ University Logo
- Social Media Icons (GitHub, Instagram, LinkedIn)

### 3. `Team_Profiles/`
Organized photos of the newsletter team and contributors.
- **`Original/`**: Uncropped, original aspect ratio profile photos.
- **`Circular/`**: Processed, circular-cropped profile photos ready for insertion into the newsletter layout.

### 4. `Design_Assets/`
Various graphical elements and backgrounds used to build the newsletter pages.
- **`Backgrounds/`**: Quantum-themed backgrounds, profile backdrops, and illustrative drawings (e.g., human-robot diagrams, campus drawings).
- **`Elements/`**: Section-specific decorative elements (e.g., Coordinator's Note, Publications, Research Spotlight).

### 5. `Event_Photos/`
Photos and illustrations related to specific CQTCS events.
- Inauguration group photos and block designs
- Christ University campus drawing
- Human-robot interaction diagrams

## 📝 Naming Conventions
Files have been standardized to use hyphenated lowercase naming or clear PascalCase to ensure consistency and readability across different operating systems and design software.
